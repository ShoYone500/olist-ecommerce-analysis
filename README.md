# Olist E-commerce Data Analysis

Brazilian e-commerce data analysis using SQL, Python, pandas, SQLite, and matplotlib.

## Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist.

The analysis focuses on four areas:

- Monthly sales trends
- Revenue by product category
- Revenue by customer state
- Repeat customer behavior

## Tools

- Python
- pandas
- SQL
- SQLite
- matplotlib

## Key Findings

- Orders and revenue generally increased from 2017 to 2018.
- Health & Beauty generated the highest category revenue.
- São Paulo (SP) generated the highest revenue mainly because of its large number of orders.
- Repeat customers represented about 3.0% of customers but generated about 5.5% of total revenue.
